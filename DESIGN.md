# Design System: 347movies — "The Projection Booth"
**Project:** 347movies (https://347movies.pages.dev) — a free cinema of the public domain. Films stream embedded from the Internet Archive; ads never interrupt a film.
**Source of truth:** `public/css/style.css` (the shipped stylesheet — every value below is the live value), `public/index.html` (page anatomy).
**Grounded in the code, not a screenshot:** synthesized directly from the production CSS/HTML, so tokens here match the deployed site exactly.

## 1. Visual Theme & Atmosphere

The site is a **theater in the dark**: cold-black walls, one warm tungsten lamp, and warm screen-white text — the "Projection Booth" concept made literal. The palette is deliberately bipolar: near-black, blue-tinted neutrals for the room, and a single amber accent that always reads as *projector light*. Nothing else competes with it.

The mood is **nocturnal, reverent, cinematic** — a quiet archive, not a streaming bazaar. Density is medium-low: generous vertical rhythm (64px hero padding, 28px section padding), lots of dark negative space, and information presented in small, disciplined doses. The hero is the signature moment: a static radial pool of amber light spilling down from the top of the viewport, as if from the projection booth above the headline.

Type carries the personality. A 1930s marquee face (Limelight) is reserved for display moments — wordmark, hero headline, 404 — evoking a cinema facade's neon sign. A utilitarian sans (IBM Plex Sans) does all reading, and a monospace (IBM Plex Mono) is used for every piece of "film-slate" metadata: eyebrows, years, runtimes, labels, uppercase chips, buttons. The system's voice is "marquee meets film canister label."

Motion is restrained and purposeful: cards lift 3px on hover with a whisper-soft shadow; page navigations cross-fade via View Transitions (progressive enhancement, Chromium-only); everything is disabled under `prefers-reduced-motion`. Two orchestrated beats on load, then quiet: the hero beam **strikes like a projector lamp** (1.6s warm-up — fade in, a single dip at 72%, then steady), and the 404 marquee **strikes like a tired neon sign** (2.2s — catches, dips twice, settles). Under reduced motion the beam and the sign are simply on, no animation. The reduced-motion kill list is CI-guarded: a smoke invariant fails if a new `animation:` ships without a kill-list entry. The feel is archival and unhurried.

## 1b. The city outside the booth (2000s New York)

347 is the NYC area code, so the theater sits in 2000s Manhattan. Behind the dark room,
night-skyline photographs (the World Trade Center era) glow through as atmosphere — each
dimmed hard behind the content so text stays AA while the city's amber windows echo the
projector light. They are CSS variables on `:root`.

**The home hero rotates.** Four photos crossfade slowly (36s cycle, 9s each) behind a
fixed scrim — the city breathing behind the booth. The first slide is the LCP image
(`fetchpriority="high"` preloaded in `<head>`); slides 2–4 load as CSS backgrounds.
Under `prefers-reduced-motion` the animation dies and the first photo simply shows.

| Surface | Variable | Role | Treatment |

| Home hero — slide 1 (LCP) | `--img-hero` / `--img-rotate-1` | `public/images/01-nyc-skyline-night-hero.jpg` (night skyline across the water) | Full-bleed cover behind `.hero-scrim` (radial center scrim + dark top/bottom gradient); the amber beam reads as projector light over the city. |
| Home hero — slides 2–4 | `--img-rotate-2/3/4` | `public/images/04-nyc-lower-manhattan-skyline.jpg` (dusk skyline), `05-nyc-brooklyn-sepia-noir.jpg` (sepia bridge), `06-nyc-twilight-notfound.jpg` (purple twilight) | Same scrim; crossfade keeps exactly one photo dominant. |

**Drop-in gallery flow (no CSS edits).** The `--img-*` block in `style.css` is delimited by
BEGIN/END generated markers and regenerated by `npm run images`
(`scripts/register-images.mjs`): drop a photo into `public/images/` named `nyc-*.jpg` and
re-run. A photo joins the hero rotation automatically; to pin one to a named role, name it
`...-hero.jpg`, `...-noir.jpg`, `...-skyline.jpg`, or `...-notfound.jpg`. Existing roles are
never displaced by a new photo (new photos only join the rotation). **Rotation order is
tunable with a numeric prefix** — `01-` leads the crossfade, `02-`, `03-` follow, then the
rest by name. The script also keeps the hero/noir LCP preloads in sync and writes
`public/images/registry.json` (gitignored) for transparency.

## 2. Color Palette & Roles

Dark-only theme (`color-scheme: dark` — native controls render dark). All colors are CSS variables on `:root`; hex values below are the exact shipped values.

### Neutrals — the theater room
| Descriptive Name | Hex | Functional Role |
|---|---|---|
| **Cold Black Wall** | `#0c0d11` | Page background (`--bg`); the room itself. Also `theme-color` and the sticky header's 92%-opaque backdrop. |
| **Raised Slate** | `#14161c` | First-level surface (`--surface`): cards, chips, inputs, selects, affiliate slots, ad slots. |
| **Deep Slate** | `#1c1f27` | Second-level surface (`--surface-2`): watch buttons, skeleton lines, poster placeholders, hero search input backdrop. |
| **Hairline Border** | `#272b36` | All 1px borders (`--border`): cards, inputs, chips, header/footer rules, dashed ad-slot outlines. A cool gray that reads as "edge of the dark," never harsh. |
| **Warm Screen White** | `#ede9df` | Primary text (`--text`). Notice it's warm-tinted — it reads as light cast on a screen, not pure white. |
| **Muted Lavender-Gray** | `#a29ca9` | Secondary text (`--muted`): nav links, years, subtitles, placeholder states, film-slate labels. A faint cool cast that keeps the room dark while staying legible. |
| **Body Secondary** | `#cfcbd8` (dark) / `#4a4438` (light) | Tertiary text for long-form reading (movie descriptions, prose paragraphs/list items) — `--body-secondary`. One step brighter than muted, one step darker than screen white. |

### The single accent — projector light
| Descriptive Name | Hex | Functional Role |
|---|---|---|
| **Tungsten Amber** | `#f2a93b` | The one and only accent (`--accent`). Used for: brand wordmark, hero eyebrow + "Surprise me", section eyebrows, see-all links, hover/active states, focus rings, buttons, license chips, source/back links, the 404 numeral, footer tagline. It is *always* the projector's light — never decorative. |
| **Amber Ink** | `#1a1206` | Text on amber (`--accent-ink`): search buttons, CTA buttons, skip-link. Dark warm brown for contrast on the bright accent. |
| **Amber Glow** | `rgba(242,169,59,0.18)` | The projection beam in the hero (radial gradient, strongest at top), the tap-highlight color, and the halo behind card borders on hover. |

| Descriptive Name | Hex | Functional Role |
|---|---|---|
| **Fade Red** | `#e07a7a` | Destructive action only — the "Clear watchlist" button on hover. The room's one alarm light. |
| **True Black** | `#000000` | Behind the player iframe (`.player-wrap`) — the screen when dark. |

### Day mode (the booth at noon)

The theater **defaults to the visitor's system preference** (`prefers-color-scheme`),
and the header `.theme-toggle` (sun/moon pill) overrides it: `app.js initTheme` sets
`data-theme="light"` on `<html>` and persists the explicit choice in localStorage
(`347movies.theme.v1`) — nothing leaves the browser. A visitor who never toggles follows
their OS; a manual choice always wins until changed. The `[data-theme="light"]` block
re-tokens the whole system; the night photos are washed out by light scrims so the city
reads as a pale backdrop and dark text stays AA.

The light tokens (all verified ≥4.5:1 on their pairs):

| Token | Value | Note |
|---|---|---|
| `--bg` | `#f4f1ea` | Warm paper; also the light `theme-color`. |
| `--surface` | `#ffffff` | Cards, chips, inputs. |
| `--surface-2` | `#e9e4d8` | Watch buttons, skeletons. |
| `--border` | `#d6cfbf` | Hairlines. |
| `--text` | `#211d15` | Dark warm ink. |
| `--muted` | `#5f5849` | Secondary text (5.56:1 on surface-2). |
| `--body-secondary` | `#4a4438` | Long-form reading (8.56:1 on bg). |
| `--accent` | `#9a5b00` | Deep amber — link/text contrast on the light room (4.81:1 on bg). |
| `--accent-ink` | `#ffffff` | Text on the deep-amber buttons (5.43:1). |

Only surfaces with imagery or a hardcoded dark fill need explicit light overrides
(`.site-header`, `.hero-scrim`, the genre hero, `.hero-search input`, `.page-head`,
`.notfound`); everything on the `--*` tokens switches by itself.

**Film grain in day mode.** The noon wash is pale, so the hero carries a whisper of
analog texture to keep the booth cinematic: a `.hero::after` overlay of SVG noise (a
`data:` URI — allowed by the CSP's `img-src data:`, rendered once and tiled at 180px,
zero requests) sits above the scrim and below the copy at ~0.06 opacity with
`pointer-events: none`, so it never touches AA. It breathes slowly
(`projector-flicker`, 5s — the lamp holding its beam on a sunny room); under
`prefers-reduced-motion` the animation dies and the grain stays static. Dark mode needs
none of this — the night photos and the tungsten beam already carry the mood, so the
grain is day-mode only.

### Rules of use
- Amber is **never** applied as background to content surfaces; it is foreground light or an outline. The only amber fills are interactive controls that *act* (search buttons, CTAs) and the hero beam.
- Depth is signaled by surface lightness (`#0c0d11` → `#14161c` → `#1c1f27`), never by color hue shifts.
- Text hierarchy is warm-to-cool: `#ede9df` → `#cfcbd8` → `#a29ca9` (dark); `#211d15` → `#4a4438` → `#5f5849` (light).

## 3. Typography Rules

Three self-hosted WOFF2 faces, all `font-display: swap`, preloaded in the head (only the three critical weights; no web-font FOIT):

| Face | Weight(s) | Character | Role |
|---|---|---|---|
| **Limelight** (1930s marquee face, fallback Georgia serif) | 400 only | Condensed, Art-Deco theatrical caps | Display moments ONLY: brand wordmark, hero h1 (`clamp(1.8rem → 3.1rem)`, +1px tracking, lh 1.15), the 404 numeral (4rem), poster placeholders, footer tagline. Never body text. |
| **IBM Plex Sans** (fallback system-ui stack) | 400, 600 | Clean, neutral grotesque | All reading and UI: body copy (1rem/1.5), section h2 (1.35rem/600), movie h1 (`clamp(1.5 → 2.2rem)`/600), page/prose h1 (1.8–1.9rem/600). Headings get ~0.2px tracking; body is untracked. |
| **IBM Plex Mono** (fallback ui-monospace stack) | 400, 500 | Slate, utilitarian | Film-slate metadata exclusively — the "data voice": section eyebrows (0.68–0.72rem, +3px tracking, UPPERCASE), film years & labels, genre chips, buttons, see-all links, `Surprise me`, pagination, watch buttons, `code` in prose, the results count, ad-slot labels. Almost always UPPERCASE with wide tracking. |

### The wordmark is the marquee sign

The brand is **two-tone Limelight**: `347` is the glowing marquee numeral — amber with a
tight tungsten text-shadow (`0 0 10px rgba(242,169,59,0.4)` + a wider 0.18 halo), echoing
the 404's neon sign — and `movies` is the marquee's painted letters in warm screen white
(`--text`), set slightly smaller (0.78em). The play triangle is gone: the number is the
icon. In day mode the glow drops (it would read as a smudge on paper) and the numeral
keeps the deep-amber `--accent`. The numeral is the one always-lit part of the sign.

### Hierarchy conventions
- **Eyebrow → heading** pairing is the system's signature rhythm: a tiny amber mono eyebrow (e.g. "NEW ARRIVALS") sits above a sans-serif h2. The amber mono strip is the section's film title card.
- Display headlines use `text-wrap: balance` so no lone word ever hangs (widows controlled).
- Body copy in prose is `#cfcbd8` (never full white — it's a lit screen, not a document).
- Code / technical references (archive.org identifiers, embed paths) render in mono with an amber tint and a raised-slate chip background — treated as film-slate data.

## 4. Component Stylings

### Buttons
- **Primary (search/CTA):** pill-shaped (999px radius), solid **Tungsten Amber** `#f2a93b` fill, **Amber Ink** `#1a1206` text, weight 600. Padding 8–12px × 14–22px depending on context. Hover: no color change — the amber *is* the state; focus is a 2px amber outline with 1px offset.
- **Ghost (watchlist "Clear"):** transparent fill, 1px hairline border, muted text; hover shifts to **Fade Red** `#e07a7a` text + border.
- **Watch buttons (card save toggles):** full-width bar at the card's foot — deep slate fill, hairline top border, mono UPPERCASE muted text; saved state turns text + border **Tungsten Amber**. Hero variant is a standalone pill.
- All interactive controls: `touch-action: manipulation` (no double-tap zoom delay) and a `rgba(242,169,59,0.18)` tap-highlight instead of the browser's gray flash.

### Cards / Containers
- **Poster cards:** `#14161c` raised-slate fill, 1px hairline border, **10px radius** (`--radius`) — "cleanly rounded, not pill, not sharp." Poster area is fixed 3:4 (`aspect-ratio`), `object-fit: cover`, deep-slate placeholder. Hover: lift 3px (`translateY(-3px)`), border warms to amber, whisper-soft diffused shadow (`0 6px 22px rgba(0,0,0,0.35)`) plus a faint amber halo ring.
- **Skeleton cards:** mirror the real card's geometry (3:4 poster box + title/year lines) so results pop in with zero layout shift; skeleton lines are deep-slate bars with 4px radius.
- **Ad slots:** reserved space, **dashed** hairline border, centered mono label — visibly a *placeholder for a future ad network*, never a broken element. Leaderboard ≥90px, sidebar ≥250px. Every page type carries a slot: home has a top + mid-page leaderboard (`leaderboard` / `leaderboard-2`); search/browse/watchlist carry a top leaderboard; movie/genre/tv carry two sidebar slots (`sidebar` / `sidebar-2`). Never over or inside the player.
- **Support:** a quiet amber "Buy me a coffee" link in the footer (`footer-coffee`) and a bordered `support-box` on the movie/destination sidebars — the viewer-funded alternative to ads, never over the player.
- **Player wrap:** true-black screen behind the player, 10px radius, hairline border, and the same amber light-pool gradient at its top — "the projector is on, above the screen." The default occupant is the archive.org embed `<iframe>` (no-JS path); when a visitor picks a direct stream the same shell holds a native `<video class="player">` (`controls`, `playsinline`, fullscreen via native controls) so the frame never changes shape.
- **Playback controls (quality + server):** a `.player-tools` row sits directly under the player (`margin-top: 14px`) — "the projector's controls under the screen." It holds up to two mono-labeled selects as columned pairs (`.player-tools__control`: uppercase 0.68rem film-slate label over a select): **Quality** (only when an item has ≥2 playable derivatives — h.264 first, then largest) and **Server** (`Embed player` / `Direct stream` / `Mirror node`, the mirror only when archive.org exposes a `server`+`dir` node). The selects follow the form control treatment (raised-slate fill, hairline border, 8px radius, mono, 2px amber focus ring); the embed is the default and app.js swaps in the native `<video>` on a non-embed choice — real bytes stream from archive.org, never hosted or proxied.
- **Affiliate / prose surfaces:** raised slate, 1px border, 10px radius; prose pages cap at 720px width.

### Inputs / Forms
- **Search inputs:** pill-shaped (999px), deep-slate or raised-slate fill, 1px hairline border, screen-white text. Focus: 2px amber outline with 1px offset, border goes transparent — the outline *replaces* the border, no double-line.
- **Selects (filters):** raised slate, hairline border, 8px radius (the one shape that's subtly squared — form controls read as "utilitarian," not theatrical), mono font, uppercase.
- Labels are visually hidden (`.visually-hidden`) — the placeholder + pill carries the affordance; the label remains for screen readers.

### Status & edge states
- **Empty states** (`.empty`, watchlist empty): centered, muted, with an amber pill CTA when action is offered — "an invitation to act, not a dead end." Copy is directive, in the interface's voice: search's no-results state echoes the query and offers the next step (try another term, or browse the catalog — TV-aware); the empty watchlist names the action ("Browse the catalog and save a film") and keeps the privacy promise; the browse empty-filter view says what to do next (different filters or sort); import failures explain what was wrong, that nothing changed, and where a valid file comes from; the noscript fallbacks point to the one real next step (enable JavaScript) and the archive.org source for no-JS visitors.
- **404:** the numeral in 4rem Limelight amber, centered, 80px vertical padding — the marquee sign left on; on load it flickers on like a tired neon tube, then settles (disabled under reduced motion).
- **Focus:** global `:focus-visible` is a 2px amber outline, 2px offset. The cross-origin player gets a mirrored focus ring on its wrapper (the iframe's own outline would clip at the rounded edges). Sticky header + `scroll-margin-top: 80px` keeps focused elements from hiding under it.

## 5. Layout Principles

- **Single fluid column, capped.** Everything lives in `.container` at **1120px max-width** with 16px horizontal padding; full-bleed only for the sticky header, footer, and hero beam.
- **Mobile-first responsive grid.** Poster grids scale by viewport: 2 columns (base) → 3 (≥640px) → 4 (≥900px) → 6 (≥1120px). Gap 14px. On the wide layout the grid is nearly edge-to-edge with the cap — the catalog *fills* the room.
- **Vertical rhythm.** Hero pads 64px top / 40px bottom; sections run 28px vertical padding; the page-head runs 32px; the footer sits 40px below content, 28px internal padding. Spacing is generous and consistent — the archive breathes.
- **The detail-page two-column split** (≥900px): film content in the flexible main column, a fixed **300px sidebar** for the ad slot + affiliate disclosure; within the film body, a 220px poster column beside the synopsis. The sidebar never wraps under the player.
- **Center-line hero.** The hero is vertically centered composition (eyebrow → h1 → sub → search → genre chips), a deliberate full-width "marquee moment" above the catalog grid. The amber beam radiates from `50% -12%`.
- **Alignment discipline.** Section heads are baseline-aligned (eyebrow+h2 left, "See all →" right). Chips, buttons, and inputs all share pill geometry so the interactive layer reads as one family. Left/right structural padding respects `env(safe-area-inset-*)` on notched devices.
- **No inline styles.** All spacing lives in classes; the CSS file is the single source of layout truth (class names are also JS hooks and smoke-suite contracts — renaming a class is a breaking change across `app.js` and `scripts/smoke.mjs`).
